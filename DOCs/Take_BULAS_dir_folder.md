**Sempre antes de trazer os arquivos vá atualizar a branch DOCS**

1. Traga a branch remota DOCS localmente com

```
 git switch DOCSS
```

2. Atualize ela

```
    git pull
```

3. Retorne para a sua branch

```
git switch sua-branch
```

4. Pegue o arquivo da branch DOCS

```
 git checkout DOCS -- BULAS_dir
```

5. Pronto ela está na sua branch :D
